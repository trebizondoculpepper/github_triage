# TypeScript migration decision

Recorded owner preference for all maintained first-party source, contributor scripts and executable research examples to use strict TypeScript (#91). Defined behavior-preserving migration, Node 20 emitted-artifact compatibility, full checking coverage, updated execution/helper paths and coordination with active source PRs. Existing JavaScript architecture preferences are superseded; no source migration or runtime change performed by the designer.

Owner clarified that deliberately chosen ancillary languages such as Datalog remain allowed. Added the explicit source-language policy to AGENTS.md and architectural benefits/tradeoffs to the contract; generated JavaScript is distinguished from maintained source.
